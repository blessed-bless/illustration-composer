## Найденные и исправленные дефекты

1. **P1: импорт через innerHTML недостаточно защищён.** База `src/recolor.js:20–22` обходила root и оставляла `<style>`, внешние use/ресурсы, namespace-элементы. Новая allowlist проверяет весь документ до добавления в HTML; SVG с неподдержанными возможностями отклоняется с причиной.
2. **P2: потеря атрибутов корневого SVG и viewport.** База `src/recolor.js:36–37` сериализовала только детей: пропадали fill/stroke, процентный rect 100×100 становился 800×600 на большом холсте. Root теперь сохраняется как nested SVG, физические единицы переводятся при 96 dpi, preserveAspectRatio сохраняется.
3. **P2: конфликт ID при дублировании и повторном экспорте.** База `src/app.js:36–39`, `src/recolor.js:37` копировала исходные ID. Префиксы `item-uid`/`lib-id` применяются к ID, url(#id), href и xlink:href. Проверен экспорт двух копий импортированного объекта с градиентом/use.
4. **P2: неполная перекраска.** База `src/recolor.js:23–30` обрабатывала лишь fill/stroke потомков; inline CSS и stop-color обходили схему. Теперь безопасные inline-свойства разворачиваются в атрибуты, учитываются root и stop-color, в том числе неявные black/currentColor. Для невалидного цвета nearestRole возвращает null. Значение stop-color по умолчанию black и отсутствие наследования сверены с [SVG 2](https://www.w3.org/TR/SVG/latest/pservers.html#StopColorProperty).
5. **P2: изменение размера фоновых объектов и ручных добавлений.** База `src/app.js:23–25` делала фон на 30% крупнее, а библиотека брала новый baseK независимо от fitted композиции. Теперь sc общий, gs масштабирует также расстояния между центрами.
6. **P2: загрузка hex-текста не работала.** База `src/app.js:155` содержала два байта U+0008 вместо буквального `\\b`; regex не находил hex-цвета. Исправлено, accept дополнен .txt/.hex. При семи цветах фоновые b1/b2 выводятся из новых m1/m3, вместо сохранения старой схемы.
7. **P2: ответ ИИ не проверялся как схема.** База `src/compose.js:69–74` допускала повторы, неверные типы и неконтролируемое число объектов. Добавлены проверки main/bg/why, дедупликация, лимиты 4/3, noBg и таймаут 15 секунд. Явный bg:[] больше не заменяется случайным фоном. Ошибки дают локальный подбор с сообщением.
8. **P2: запоздавший ИИ перезаписывал ручные действия.** База `src/app.js:68–89` не отслеживала актуальность запроса. Ручное изменение/undo/pointerdown инвалидирует результат; устаревший запрос не переключает кнопки нового запроса. Успешная замена композиции сбрасывает drag.
9. **P2: ручная смена состояния игнорировала noBg.** База `src/app.js:122` переключала без проверки. Ограничение теперь действует и в кнопке, и в act.
10. **P2: перекраска яркостной маски меняет форму.** Независимое ревью показало изменение alpha двух половин маски `[255,0] → [221,132]` при orange/bg. Маски исключены из поддерживаемого импорта; изменение их семантики не маскируется успешной загрузкой.
11. **Улучшения редактора:** отмена до 60 состояний, Ctrl+Z/Cmd+Z, Escape, привязка 10 единиц с Shift, pointer capture/cancel, ручки поворота/масштаба всей группы, seed вместо Date.now, доступные названия и focus, статус aria-live. Export исключает весь служебный слой; object URL освобождается с задержкой после скачивания.

## Оставшиеся ограничения

- Реальный API Claude и доступность `claude-haiku-5-5` не проверялись платным запросом. Заглушки доказывают протокол обработки/отката, а не существование модели в аккаунте.
- Figma/Illustrator нативно не запускались. Проверена валидность XML и изолированный Chromium; это не заменяет тест импорта в конкретной версии этих редакторов.
- Абсолютно одинаковые габариты L/S требуют растяжения по осям либо правки исходников; оба варианта нарушают условия. Оставлен равномерный масштаб с исходным допуском ≤0,262%.
- Сложные CSS, mask, filter и внешние ресурсы отклоняются. Это сознательная граница импорта: не принимать файл с незаметно изменённым рисунком. Текст и системные шрифты могут выглядеть по-разному на разных устройствах.
- Локальная семантика и nearestRole для произвольных импортов остаются эвристиками. Произвольную метафору и авторские роли неизвестного цвета невозможно гарантировать текущим небольшим словарём.
- noBg оставлен как в manifest: оснований назначать новые запреты нет. Автораскладка не обещает отсутствие всех визуальных пересечений; фон намеренно обрезается краем.
- История отменяет состояния композиции и параметры, но не удаляет загруженные ресурсы библиотеки и не меняет API-ключ. Ключ по прежнему хранится в localStorage по существующему интерфейсу.
- Публикация на GitHub Pages не выполнялась; изменения и доказательства находятся в локальной ветке.
