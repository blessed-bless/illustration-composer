# Portfolio style standard

Target look: one developer, calm and concrete. Behavior stays the same; style aligns.

## Layout

```
src/               # ES modules
catalog/           # SVG library + manifest
tests/
server.mjs         # static file server
Makefile           # run test lint fmt
README.md
```

No second JS lint stack without asking (this repo has none yet).

## Comments / README

- Comments: English only, explain *why*
- README: one sentence · screenshot · capabilities · mermaid · stack · run · config
- No AI authorship sections, badge walls, or emoji lists

## Commits

Conventional Commits, English, short. Sole human author.
